# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Baby LLM is a privacy-first, zero-cloud architecture designed to protect personal user data, sensitive memory graphs, and encrypted attributes at rest.

If you discover a security vulnerability or potential data leakage risk in Baby LLM:

1. **Do not create a public GitHub issue.**
2. Send an email describing the issue, reproducible steps, and potential impact to `webdev.hemant@gmail.com`.
3. You will receive an acknowledgment within 48 hours.
4. We will coordinate a fix and release an updated version before public disclosure.

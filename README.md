# Baby LLM
*The Privacy-First, Self-Evolving Local Memory & Life Success Engine*

Baby LLM is an autonomous, local-first cognitive companion designed to run completely offline on consumer hardware with zero latency overhead on the real-time chat path.

## Key Features
- **Zero-Lag Fast Path**: In-memory episodic ring buffer and sub-20ms hybrid retrieval (SQLite FTS5 BM25 + LanceDB vector search).
- **Asynchronous REM Dream Engine**: Background consolidation of atomic SPO facts, bi-temporal conflict resolution (`valid_from` / `invalid_from`), and Ebbinghaus forgetting curves with YMYL shields.
- **Personal Success Agent**: Morning Intention Briefs, Gentle Curiosity Protocol, and Accountability Watchdogs.
- **Universal Model Context Protocol (MCP)**: Memory layer accessible from Claude Desktop, Cursor, and CLI tools.
- **Bidirectional Vault Sync**: Native integration with local Markdown and Obsidian vaults.
